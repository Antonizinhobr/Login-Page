## 🚀 Como Executar o Projeto

### ✅ 1. Clonar o repositório

```bash
git clone https://github.com/seuusuario/login-page.git
cd login-page
```

---

### 💻 2. Executar no navegador (duas opções)

#### **Opção A: Usando o Live Server (VS Code)**

1. Abra o projeto no VS Code:

```bash
code .
```

2. Instale a extensão **Live Server** (se ainda não tiver).
3. Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"**.
4. O navegador será aberto automaticamente com a aplicação rodando localmente.

---

#### **Opção B: Usando um servidor HTTP local**

##### No **Linux** ou **Windows** (com Python instalado):

- Python 3.x vem com um servidor HTTP embutido. Basta executar:

```bash
# Navegue até a pasta do projeto (onde está o index.html)
cd login-page

# Execute o servidor (porta 8000 por padrão)
python -m http.server
```

- Depois, abra o navegador e acesse:
```
http://localhost:8000
```
